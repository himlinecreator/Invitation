ROYAL 9:16 INTERACTIVE WEDDING WEBSITE

Open index.html in a browser.

- Animated royal hero entrance
- Floating/glowing floral frame

- Scroll reveal animations for invitation and events

- Animated falling royal petals

- Animated event cards

- Back-to-top button
- Toast messages and micro-interactions
